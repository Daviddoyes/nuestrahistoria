#
# El PDF repite el mismo reto cambiando un número, una máquina o el tiempo
# que se hizo ese día. Eso es un plan de entrenamiento, no un perfil.
#
# Cuatro reglas:
#   · fuera el umbral de marca — "Correr 10 km", no "en menos de 45 min"
#   · fuera el contexto — la ruta de 50 km se cuenta una vez, no siete
#   · una sola serie de cardio, no una por máquina de gimnasio
#   · solo los hitos que se cuentan: 5K, 10K, media, maratón, ultra
#
# Formato: la línea sin sangrar es el gooal que se queda; las que empiezan
# por "<" son los que absorbe. Borra una línea "<" para salvar ese reto,
# o un bloque entero para deshacer el grupo.
#
# Un bloque titulado BORRAR elimina a sus miembros en vez de fundirlos.

# GooALS — deporte: fuera lo que no se puede contar
#
# La regla es de David: si no hay foto, no hay gooal. Nadie sube a un muro
# "Nadar 100 m con respiración bilateral" ni "Hacer un cutback básico". Como
# entrenamiento están bien; como experiencia de vida, no.
#
# Tres grupos se van:
#
#   · Títulos que quedaron cojos al quitarles el número en las fusiones.
#     "Hacer flexiones seguidas", "Completar una ruta con de desnivel
#     positivo", "Hacer rounds de saco de". Eso es un fallo mío de la pasada
#     anterior, no una decisión.
#
#   · Micro-técnica: el gesto suelto en vez del logro. Todo lo que lleva
#     "básico", "controlado", "asistido" o "con supervisión" es una clase,
#     no una historia. También los 36 "Aprender a frenar en T" y compañía.
#
#   · Deportes que no conoce nadie: korfball, kin-ball, bochas, footgolf,
#     sepak takraw. Si alguien los echa de menos, ya los sugerirá.
#
# Lo que entra a cambio está en nuevos_deporte.txt: 45 benchmarks de fuerza
# y calistenia, que sí tienen número y sí tienen foto.
#
# Para salvar uno, borra su línea "<".
